# ⚔️ Game of Thrones Trivia App

A retro-styled trivia game about Game of Thrones for iPhone, built with SwiftUI.

## Features

- **8 Game of Thrones Trivia Questions** - Test your knowledge!
- **Tap-Based Gameplay** - Simple and intuitive controls
- **Retro Aesthetic** - Pixelated fonts, neon colors, and retro design
- **Score Tracking** - Keep track of your correct answers
- **Instant Feedback** - Know right away if your answer is correct

## Tech Stack

- **SwiftUI** - Apple's modern UI framework
- **Swift** - iOS development language
- **Minimum iOS 15.0**

## How to Run

### In Xcode

1. Open Xcode
2. Click "File" → "Open"
3. Select this repository folder
4. Xcode will auto-detect the SwiftUI files
5. Press ▶️ (Run) to build and launch in the iOS Simulator

### Files

- `GoTTrivia/GoTTriviaApp.swift` - App entry point
- `GoTTrivia/ContentView.swift` - Main game UI and logic
- `GoTTrivia/Models.swift` - Trivia questions data

## Game Rules

1. You'll be asked **8 trivia questions** about Game of Thrones (randomized order)
2. Each question has **4 possible answers**
3. **Tap the answer** you think is correct
4. Get instant feedback (✓ CORRECT! or ✗ WRONG!)
5. Your score increases with each correct answer
6. After all questions, see your final score and percentage
7. Tap "PLAY AGAIN" to restart with new randomized questions

## Trivia Questions Included

- House Stark's motto
- King of the Seven Kingdoms at the start
- Currency of Westeros
- House Baratheon's words
- Daenerys Targaryen's titles
- Iron Throne ruler at the start
- House Lannister's words
- House Stark's seat

## Sharing with Friends

### Option 1: TestFlight (Recommended)
1. Get an Apple Developer Account ($99/year)
2. Archive the app in Xcode
3. Upload to TestFlight
4. Invite friends via email - they download and test on their iPhones

### Option 2: Direct Installation
1. Connect a friend's iPhone to your Mac
2. Build and run the app to their device from Xcode
3. They'll need to trust your developer certificate

### Option 3: App Store (Future)
1. Submit to App Store for review
2. Once approved, friends download it for free
